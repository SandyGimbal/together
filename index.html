Keunggulan Utama

Teknologi Geospatial Bertemu Romantisme

Dibangun dengan standar keamanan tertinggi, performa Leaflet.js yang mulus, dan visual citra satelit nyata.

Citra Satelit Beresolusi Tinggi

Gunakan citra satelit resmi Esri World Imagery, Street View, Hybrid jalan, dan kontur medan untuk mengenali posisi pasangan secara akurat.

Sinkronisasi Realtime Dua Arah

Didukung Firebase Realtime Database dan Geolocation API dengan algoritma throttling cerdas untuk hemat baterai dan paket data.

Privasi & Keamanan Ketat

Hanya dua orang dalam satu Couple Room. Dilengkapi Firebase Security Rules, mode jeda lokasi, dan ghost mode yang dapat Anda kendalikan kapan saja.

Kalkulator Jarak Haversine

Ketahui jarak eksak antara Anda dan pasangan dalam meter atau kilometer beserta arah kompas dan estimasi pergerakan.

Notifikasi Kedatangan Geofence

Dapatkan peringatan lembut dan lonceng romantis saat pasangan tiba di rumah, kampus, kantor, atau ketika kalian sudah saling berdekatan.

Telemetri Pasangan Lengkap

Pantau persentase baterai ponsel pasangan, status pengisian daya, kecepatan berkendara, dan indikator kesegaran lokasi (live/recent/offline).

Pasang Aplikasi TOGETHER

TOGETHER adalah Progressive Web App (PWA) resmi. Anda dan pasangan dapat memasangnya langsung di HP (Android/iOS) atau Laptop tanpa perlu Play Store, hemat baterai, dan bisa langsung dibuka dari layar utama HP.

📱 Panduan Pasang Manual di Browser HP:
1. Android (Brave / Google Chrome / Edge)
Ketuk ikon titik tiga (⋮) di sudut kanan atas browser → pilih "Tambahkan ke Layar Utama" atau "Instal Aplikasi".
2. iPhone / iPad (Safari)
Ketuk tombol Bagikan (Share ⎋) di bilah bawah → gulir ke bawah → pilih "Tambah ke Layar Utama" (Add to Home Screen).
3. Komputer / Laptop (Desktop Chrome / Brave)
Klik ikon Instal (⊕) di sebelah kanan bilah alamat (URL bar) browser di atas.
